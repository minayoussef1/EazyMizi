# EasyMizi — تطبيق أندرويد

## الهيكل
- `web/` : الواجهة (index.html) وجسر الإشعارات (native.js).
- `core/` : المنطق والاختبارات. الاختبارات بتتشغل تلقائيًا مع كل بناء.
- `.github/workflows/android.yml` : بيبني ملف APK تلقائيًا.

## الخطوات
1. اعمل Repository جديد على GitHub وارفع الملفات دي (ماتحطش `android/` ولا `node_modules/`).
2. روح تبويب **Actions** واستنى البناء يخلص (5-10 دقايق).
3. افتح الـRun الناجح، وفي آخره **Artifacts** نزّل `vitalis-debug-apk`.
4. فك الضغط وانقل `app-debug.apk` للتليفون وثبّته (لازم تسمح بالتثبيت من مصادر غير Play Store).

## ملاحظات
- التثبيت ده للتجربة. للنشر على Google Play محتاج توقيع (keystore) وملف AAB، وده خطوة لاحقة.
- التذكير بيتجدد كل مرة تفتح التطبيق. لو ما فتحتوش لفترة مش هيفكرك لحد ما تفتحه تاني.
- أول مرة تفتح التطبيق على أندرويد 13 وفوق، هيطلب إذن الإشعارات.
- إعداد الإشعارات (تشغيل/إيقاف، ووقت التذكير) لسه ما اتعملش في الواجهة، والقيمة الافتراضية 2 الضهر.
